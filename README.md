
# INFR3120 Assignment 2 - Express Portfolio

## Project Description

This project is a personal portfolio website created
using Node.js, Express.js, and the EJS templating engine.

The website contains four pages:
- Home
- About Me
- Projects
- Contact Me

The purpose of this assignment is to demonstrate
Express routing, EJS templates, reusable partials,
and cloud deployment.

## Technologies Used

- Node.js
- Express.js
- EJS
- Bootstrap 5
- Font Awesome
- HTML and CSS
